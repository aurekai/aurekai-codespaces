# Quickstart — aurekai-codespaces

GitHub Codespaces dev container for Aurekai.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/aurekai/aurekai-codespaces)

## What's included

- Python 3.11 base image
- GitHub CLI
- `akai` CLI installed on container create (`0.8.0-alpha.4`)

## Validate

```bash
bash tests/validate-schemas.sh
bash tests/validate-scripts.sh
```
